# Notes Generator App with React Context API and Local Storage

# Objective:

##### Build a notes app where users can create, view, edit, and delete notes with titles and content, along with a category tag.

# Requirements:

### 1.Use React Context API to manage the state globally.

### 2.Use local storage to save notes persistently so they remain available after refreshing the page.

### 3.Home page should display notes, editing a note should be it’s own page

### 4.A form for creating a new note with title, content, and category (users can choose from a pre-defined list of categories)

### 5.Full CRUD operations for notes

# Optional Areas of Development

##### Handle all of your state logic with useReducer

##### Add other properties to the notes (date, image, urgency, etc.)

##### Add search and filtering for easy navigation of notes (filter by category, date, etc.)

##### Add register and sign in pages (can save users in localStorage) - only notes from signed in user should display, only user can update their notes

##### Allow the user to add several categories to the same note

##### Allow user to make custom categories

##### Any feature you think is interesting!

# Deploy

##### The application as a static site on Render.
